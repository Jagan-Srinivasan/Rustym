FreeSans-Bengali-subset.ttf: Bengali block subset (U+0964-0965, U+0980-09FF) of GNU FreeFont's FreeSans,
licensed GPL-3+ with the GNU font exception (https://www.gnu.org/software/freefont/).
Used only as a last-resort fallback so Bengali text never renders as empty boxes
when no system Bengali font (e.g. Noto Sans Bengali) is installed.
