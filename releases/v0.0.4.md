# Rustym v0.0.4

This release fixes the Now Playing card overflowing the window, cuts the
window process' memory footprint substantially, and makes "Start minimised"
actually work at sign-in.

## 🎛️ Now Playing card can no longer slide off the display

- The Play / Pause pill and the ring buttons (like, lyrics, vinyl, visualiser,
  add-to-playlist, queue) are now a **wrapped row**, so the hero actions can
  never push the card wider than the window — previously the ~430 px row
  overflowed narrow and compact cards and dragged the whole card off-screen.
- The artwork / info / lyrics-vinyl pane columns are sized from the space that
  really remains after the artwork (the old fixed 250/200/190 px minimums
  overflowed the card on narrow windows). The artwork shrinks first, and the
  lyric / vinyl pane shrinks with the window before anything can overflow.
- Covered by unit tests: `hero_row_never_overflows` proves the hero row fits
  inside the card on every window width and layout.

## 🧠 Memory footprint: smaller and flat

Measured on a real session (Wayland, Intel GPU), window process RSS:

- **Before:** ~200 MB after launch, and it kept growing while browsing
  (older releases could climb to hundreds of MB).
- **After:** **~140 MB steady and flat** over long sessions; by fair-share
  memory (PSS) it is ~67 MB.

What changed:

- Decoded artwork cache budget reduced 96 MB → **16 MB**, and images are never
  decoded larger than 800 px on a side (the largest tile is the ~420 px Now
  Playing artwork), so a 45 px row thumbnail can no longer cost megabytes.
- glibc now returns freed pages to the OS on every cache-sweep pass
  (`malloc_trim`); previously freed cache memory stayed mapped in allocator
  arenas (~60 MB on a long session) and RSS never came down.
- The ~19 MB Noto Sans CJK fallback font is now loaded lazily, only when CJK
  characters actually appear in titles, artists or lyrics. Indic, Arabic and
  Thai fallbacks still load at startup so nothing you'd normally see changes.
- The image cache remains bounded and stale entries (plus their GPU textures
  and raw bytes) are still released every 15 s.

## 🌙 "Start minimised" works at sign-in now

Two bugs made the window pop up anyway at boot:

- The XDG autostart entry runs `rustym --show`, and a cold start ignored the
  "Start minimised" setting entirely. It now wins over `--show`: cold starts
  stay in the background with just the tray icon.
- The window process tried to minimise itself on its first frame, but Wayland
  compositors ignore an app's own minimize request before the window is
  mapped — so the window appeared anyway (and every tray-restore spawned a
  window that instantly minimised itself, making "show window" look dead).
  The self-minimise is gone; the background process owns the decision.

The existing safety net is kept: if no tray shows up within 10 s a window
still opens, so you are never left with nothing.

## 🔧 Under the hood

- `libc` dependency added for `malloc_trim` (Linux only).
- New tests: hero row layout guarantee, image-cache decode budgets unchanged
  and passing.

Build: `cargo build --release` (or grab the packages below).
