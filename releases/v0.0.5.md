# Rustym v0.0.5

UI polish for the Now Playing page: the vinyl player stays in its fixed
region, and the audio visualiser is no longer cut in half by long song
titles.

## 🎞️ Vinyl player fixed in place

- The vinyl player's size now comes from its own pane's stable height
  (clamped so the disc + its mini equaliser always fit inside the pane
  region) instead of drifting with the layout around it.
- It is vertically centred in its pane, so it always sits in the same
  fixed spot — no more jumping when titles wrap, the queue opens or the
  window resizes.

## 📊 Audio visualiser no longer clipped in half

- The visualiser's height now fills only the space that is actually left
  below the Now Playing card (64 px floor).
- Previously it was forced to a fixed minimum (116/148 px) even when a long
  song title made the card taller than that space — the visualiser then
  extended past the panel edge and was clipped in half. With a short title
  it still stretches to fill the leftover space as before.

## 📦 Packaging

- The release pipeline now explicitly drops any `-debug` / `-dbgsym`
  packages before publishing, so only the real `.deb` / `.rpm` /
  `.pkg.tar.zst` packages ever land on the release page.

## 🔧 From v0.0.4 (if you skipped it)

- Now Playing card can no longer slide off the display (wrapped action row,
  layout fitted from the space that really remains, unit-tested).
- Lower, flat memory footprint: ~140 MB steady window-process RSS
  (was ~200 MB and growing), bounded artwork cache, freed pages returned to
  the OS, lazy CJK font loading.
- "Start minimised" works at sign-in: cold starts stay in the tray, the
  window no longer self-minimises (which Wayland compositors ignore).

Build: `cargo build --release` (or grab the packages below).
