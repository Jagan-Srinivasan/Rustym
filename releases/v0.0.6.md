# Rustym v0.0.6

Follow-up UI fixes for the Now Playing page, verified against a rendered
long-title layout on a wide window.

## 🎞️ Vinyl player: truly fixed

- The vinyl's size now comes **only from the artwork column size** and it is
  anchored to the top of its pane — it sits in exactly the same spot no
  matter what happens around it: play/pause, wrapped action rows, long
  titles, opening the queue, or toggling the visualiser.
- (v0.0.5 still derived its size from the pane height, which flips between
  two very different values when the visualiser is toggled — that was the
  remaining movement.)
- Verified: the card's height is byte-identical in the playing and paused
  states, so nothing below the play/pause button can shift.

## 📊 Audio visualiser: exact fit, no clipping, no dead band

- The visualiser frame now takes **exactly the space left between the card
  and the player bar**, and the bars area is measured from the real cursor
  position inside the frame — bars always fill the frame, and the frame
  never extends past the panel edge.
- The card and the visualiser now live inside a scroll area: if a very long
  song title makes the card taller than the page, the visualiser keeps a
  96 px size and simply becomes reachable by scrolling instead of being cut
  in half at the panel edge.

## 📦 Packaging

- As before, the release pipeline drops any `-debug` / `-dbgsym` packages —
  only the real `.deb` / `.rpm` / `.pkg.tar.zst` are published.

## 🔧 Includes everything from v0.0.4 / v0.0.5

- Now Playing card can no longer slide off the display (wrapped hero actions,
  layout fitted from the space that really remains, unit-tested).
- Lower, flat memory footprint: ~140 MB steady window-process RSS
  (was ~200 MB and growing), bounded artwork cache, freed pages returned to
  the OS, lazy CJK font loading.
- "Start minimised" works at sign-in: cold starts stay in the tray.

Build: `cargo build --release` (or grab the packages below).
